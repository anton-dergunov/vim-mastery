The Vim Wilds

Short, tactile lessons that make Vim commands feel like a language you can use anywhere.

  • One idea at a time. Learn modes, movement, edits, and repeatable commands in small scenes.
  • Built for thumbs. A physical-style keyboard keeps the native phone keyboard out of the way.
  • Ready offline. Install once; lesson content and character art travel with you.
  • A scratchpad too. Twenty real files to edit freely, with no lesson and no score, open from the first day.

Install Vim Wilds
  1. Open this page in Safari.
  2. Tap Share.
  3. Choose Add to Home Screen, then tap Add.

The app will launch from your Home Screen without Safari controls.

In Chrome, open the ⋮ menu and choose Install app. The installed game opens without browser controls.

Use your browser’s Install app or Add to Home Screen option. For iPhone and iPad, switch to the Safari instructions above.

Animations stream only when needed.
