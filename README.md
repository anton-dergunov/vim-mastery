# The Vim Wilds

A mobile-first, offline-friendly prototype for learning Vim through short exercises. It uses CodeMirror 6 and the Replit Vim extension so the editor executes Vim commands directly.

## Run locally

Install dependencies once, then start the development server:

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (normally `http://localhost:5173`).

To run the native-Vim and browser conformance tests:

```bash
npm test
```
